01 · About

I've built quality systems from the inside and implemented them from the outside.

As a Quality Control Manager I built QA systems from the factory floor up; as a Senior Solutions Engineer I now implement operational technology from the outside. I understand both how factories run and how to make tools serve the way they run, including testing releases and shaping requirements before software ever reaches a customer.

More recently that means building with AI: internal tools, automations, and reporting that speed up analysis and decision support without adding headcount. The same instinct as always: if the tool doesn't fit the floor, build one that does.
